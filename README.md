# 🚌 Zajel Run – Smart Bus Booking & Tracking App

**Zajel Run** is a smart bus transportation application that allows users to easily book their seats, manage subscriptions, and track buses in real time.

The app provides a convenient and reliable commuting experience by keeping passengers informed about bus locations and estimated arrival times through real-time notifications.

## ✨ Features

- **Seat Booking:** Browse available buses and reserve your preferred seat.
- **Subscription Management:** Subscribe to available bus routes and manage your subscriptions.
- **Real-Time Bus Tracking:** Track the bus location and monitor its journey in real time.
- **Arrival Notifications:** Receive notifications about the expected bus arrival time.
- **Live Updates:** Stay informed about bus status and important trip updates.
- **User-Friendly Interface:** Enjoy a simple and intuitive booking experience.

## 🛠️ Technologies & Tools

- Flutter & Dart
- State Management: BLoC / Cubit
- API Integration: REST APIs
- Real-Time Location Tracking
- Push Notifications
- Google maps 
- Payment gateway


## 📱 App Overview

Zajel Run aims to simplify daily transportation by combining bus reservations, subscription services, and real-time tracking in one application.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Navigate to the project directory:
   ```bash
   cd zajel_run
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
